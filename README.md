# Learn and Earn — технические кейсы

Техническое портфолио образовательного проекта: диагностический Telegram-бот, платная учебная платформа и отдельная CRM для управления продажами.

Системы разрабатывались с использованием **OpenAI Codex и ChatGPT**. В рамках проекта я занимался проектированием логики, постановкой технических задач, интеграцией компонентов, тестированием и серверным развёртыванием.

## Реализованные проекты

| Проект | Основная функциональность | Технологии |
|---|---|---|
| [Free Bot](free-bot/README.md) | Два маршрута диагностики, PDF-уроки, интерактивные вопросы, прогресс, коды доступа, админка и уведомления | Python, aiogram 3, SQLite, FSM |
| [Paid Bot](paid-bot/README.md) | Восемь учебных модулей, многофайловые задания, проверка практики, кураторские темы и управление прогрессом | Python, aiogram 3, SQLite, Ubuntu VPS, systemd |
| [CRM](crm/README.md) | Web CRM, Entry Bot и Manager Bot: регистрация заявок, учёт источников, работа с контактами, назначения и роли сотрудников | React, FastAPI, PostgreSQL, Docker Compose, Ubuntu VPS, Caddy |

Образовательные боты и CRM — технически самостоятельные решения. Общая база данных и автоматическая синхронизация между ними не заявляются.

## Мой вклад

- **Проектирование:** пользовательские маршруты, состояния, роли и бизнес-логика.
- **AI-assisted разработка:** постановка задач OpenAI Codex и ChatGPT, анализ предлагаемых решений и проверка реализации.
- **Интеграции:** взаимодействие Telegram-ботов с backend-компонентами и базами данных.
- **Тестирование:** проверка пользовательских и административных сценариев, воспроизведение ошибок и контроль исправлений.
- **Развёртывание:** настройка серверного окружения, Ubuntu VPS, Docker Compose и HTTPS в соответствующих проектах.
