# Learn and Earn — техническая документация

Этот раздел дополняет [основное портфолио Learn and Earn](../README.md) и объединяет материалы трёх разработанных систем.

Здесь представлены сведения о сохранившихся материалах, историческом тестировании и пользовательских интерфейсах. Документация помогает подробнее изучить проекты, не перегружая их основные README техническими подробностями.

## Основные проекты

| Проект | Описание |
|---|---|
| [Free Bot](../free-bot/README.md) | Диагностический Telegram-бот с учебными маршрутами, PDF-материалами и сохранением прогресса |
| [Paid Bot](../paid-bot/README.md) | Образовательная Telegram-платформа с домашними заданиями, кураторской проверкой и управлением обучением |
| [CRM](../crm/README.md) | Система управления продажами с React, FastAPI, PostgreSQL и Telegram-интерфейсами |

Каждый кейс содержит описание функциональности, использованные технологии, архитектурные схемы, изображения интерфейсов и сведения о моём вкладе в разработку.

## Технические материалы

[Манифест изображений](image-manifest.csv) содержит список PNG-файлов и их контрольные суммы SHA-256.

Он предназначен для технической проверки целостности файлов и не требуется для изучения функциональности проектов.

## Статус проектов

Все три системы находятся в архивном состоянии. Последние полные версии исходного кода и серверные окружения недоступны.

Документация подготовлена по сохранившимся изображениям интерфейсов, техническим описаниям и истории разработки. Она представляет исторический опыт проектирования, AI-assisted разработки, интеграции, тестирования и развёртывания приложений.

Материалы не являются подтверждением текущей работоспособности систем или результатом нового независимого аудита исходного кода.
